Workflow

1. Edit goals with - bullets under planning sections.
2. Check goals → Plan tasks (preview & select).
3. Queue a task → Run command in OpenClaw.
4. Mark Complete when the worker finishes.

Planning blocked?

Enable Allow repeat if titles exist in tasks-log. Use Goals only to skip generic scaffold tasks. Archive done tasks or run Fresh lab to clear the board.

Build phase

Build tasks need a planning brief in reports/ first. Cards show a warning until a brief exists.

CLI backup

python -m overnight_app_maker tasks list
python -m overnight_app_maker tasks diagnose
python -m overnight_app_maker tasks archive-done
