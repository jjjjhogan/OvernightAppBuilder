# Goals Template

Fill this file with the user's goals, missions, constraints, and preferences. The more specific the goals are, the better OvernightAppMaker can plan useful autonomous work.

## Career

- Example: Grow a YouTube channel to 100k subscribers.
- Example: Launch a SaaS product by Q3.

## Personal

- Example: Read 2 books per month.
- Example: Learn Spanish.

## Business

- Example: Scale revenue to $10k/month.
- Example: Build partnerships with 5 companies.

## Automation Targets

- Example: Automate repeated weekly reporting.
- Example: Build tools that remove boring manual work.

## Constraints

- Things the agent should not do without approval.
- Preferred tech stacks.
- Working hours or quiet hours.

## Overnight App Ideas

- Problems worth solving.
- Tools that would save time.
- Product experiments to try.
