# Worker Instructions

Use these instructions when spawning a sub-agent or worker task:

```text
Complete the assigned task using the project goals and task brief.
Write artifacts into the requested output folder.
When done, append a completed task line to memory/tasks-log.md.
Never edit AUTONOMOUS.md directly.
Never perform external actions such as sending messages, posting, purchasing, or publishing without explicit approval.

Planning tasks (phase=plan): write markdown briefs, research notes, or implementation plans in reports/ or research/.
Build tasks (phase=build): read the referenced planning brief and deliver a minimal presentable static web app (HTML/CSS/JS with index.html) under apps/. Do not substitute another markdown plan for a build task.
```
